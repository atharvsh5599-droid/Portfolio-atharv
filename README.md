# Atharv Sharma Portfolio

A modern, responsive personal portfolio website for Atharv Sharma — a B.Tech Computer Science Engineering (AI/ML) student and aspiring software developer.

## Features

- Responsive light-themed layout
- Sticky navigation with active-section highlighting
- Mobile navigation menu and smooth scrolling
- Subtle reveal animations and interactive skill cards
- Education, learning journey, coding profile, GitHub, and contact sections
- No fabricated projects, statistics, or achievements

## Run locally

This is a static website with no build step or dependencies. Open `index.html` in a browser, or serve the folder using any local static server.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the source, then save. This one-time step is required before the workflow can deploy.
4. Push to `main` (or manually run the **Deploy portfolio to GitHub Pages** workflow from the Actions tab).

GitHub will publish the site at `https://<your-github-username>.github.io/<repository-name>/`. The included workflow deploys the static files automatically after every push to `main`.

## Updating content

- Update portfolio copy and links in `index.html`.
- Add future project cards inside the `#projects` section.
- Adjust colors, type, and spacing through CSS variables at the top of `styles.css`.
